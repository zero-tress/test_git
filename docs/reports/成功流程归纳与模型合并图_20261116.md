# 成功流程归纳与模型生成的合并操作图

适用交付：output/意图拿笔，输入为抓取1、抓取2、抓取4。新增入口是 workbench.html、operations.svg。此次变更实现新学习视图与模型调用入口；历史分析和原始视频继续保留。

## 学习流程

1. 已部署模型读取联合视频、源视频时间映射、源关键帧和先前部署模型的原始分析。旧的代理手工图、人工视觉补丁和 reviewed_cases 不进入新增模型阶段。
2. 模型分别判断整个任务是否成功。只有整体成功的案例可进入成功流程主图；失败、未执行或未知案例仍可提供独立的局部技能样本。
3. 成功案例中，模型标记保留范围和失败范围。两者不得重叠。失败尝试不进入成功操作节点，其源片段仍进入独立的正反例样本池，不删除原视频。
4. 模型检查成功步骤是否可保留、删除或合并，并区分“保留观察到的步骤”和“已证明步骤必要”。证据不足的必要性只能作为候选或未知，不能由程序按动作名称删步骤。
5. 模型在语义层对齐不同视频的成功路径：实例物体、颜色和位置保存在来源中；可兼容的角色、效果与条件使用共享操作节点。时序冲突或语义不兼容时保留分支并说明原因。
6. 模型输出完整的节点、边、来源路径、门控和七元组。中间门控保留 T/F/U；U 不自动放行。最后一个操作直接连接结束，结束前不加门控或完成验证。
7. 独立模型阶段复核本批次“建立稳定握持”的抓取候选，逐个输出成功/失败/未知、范围、证据和七元组。抓取不以抬离支撑面为必要定义；范围不匹配时必须保留未知。
8. 宿主程序仅校验协议、保存原始结果、按模型时间裁剪、绑定来源并自动排版。模型调用或校验失败即报错，无代理/规则补写业务结论的降级路径。

## 七元组与数据责任

保留 X、O、C_pre、C_const、E、C_post、R。E 是评价方法，必须包含 metric、success_condition、failure_condition、unknown_condition，不是动作策略或动作名称。R 是模型归纳的候选实现集合，不能把每个视频各自定义成新的技能总纲。

主图数据 merged_operation_graph.json 必须等于 success_process_model/result.json 的 response。展示用 merged_operation_view.json 只附加来源链接、切片和独立部署模型的正反例复核结果。它的原始正反例记录位于 contrastive_process_model/result.json；每个判断保留证据和模型来源。

正反例的 positive_example_ids 仅引用成功行为，negative_example_ids 仅引用失败行为；条件有无使用独立字段，不把“条件不存在”写成“行为失败”。

两个模型阶段均使用 video2op/config.py 的 V2O_MODEL、V2O_BASE_URL。当前为现有本机8032服务的 qwen3.8-27b；替换部署模型通过配置完成。模型名称、提示词或输入变化会使缓存失效。授权访问范围仍限制为现有本机8032；不申请GPU权限、不修改服务。

## 使用

在服务器既有 conda study 环境、项目根目录执行。本批次适配器使用 output/意图拿笔/跨视频模型分析 下已保存的联合观察结果和时间映射；不是重新执行全部单视频分析。

已取得现有本机8032访问授权后，执行模型阶段与导出：

~~~sh
conda run -n study python -B tools/export_cross_video_workbench.py --out output/意图拿笔 --analyze --allow-model-service
~~~

仅离线重排版，要求模型结果存在且输入指纹一致：

~~~sh
conda run -n study python -B tools/export_cross_video_workbench.py --out output/意图拿笔
conda run -n study python -B tools/verify_merged_workbench.py --out output/意图拿笔
~~~

强制重新调用使用 --force；旧的模型结果与输入先存入对应模型目录的 history。缺失/过期结果不能以程序拼图替代。

## 验证与边界

本轮增加18项契约与渲染回归，覆盖整体/局部成功分离、失败剔除与留样、保留范围不能覆盖失败范围、七元组E、正反例引用、未知范围、模型替换缓存、失败不降级，以及结束前无门控。完整499项测试与所改Python代码的Ruff检查通过。

交付验证检查原视频SHA、主图与模型输出一致性、切片SHA和回执、SVG节点、6个页面本地链接及JavaScript语法。SVG另经栅格化检查排版。服务器没有可用浏览器，本轮不宣称浏览器交互已实测。

模型提出的因果条件及必要性仍是模型候选，需要更多对照证据才能成为可执行规则。历史跨视频报告保留原始失败经过；最新成功学习主图以本报告指向的工作台和两个模型结果为准，不能把历史报告当成已更新的成功主图。
